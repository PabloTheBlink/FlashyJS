# Changelog

## 2.0.0

- Añadido `flashy.promise` con transición de carga a éxito o error en el mismo toast.
- Añadidos aro de progreso que se transforma en check o cruz, entrada spring, pila 3D y descarte por swipe con umbral de distancia o velocidad.
- Añadidos temas glass, aurora y midnight; aurora se presenta como superficie pizarra sin degradados. Avisos con descripción, avatar y acción.
- Añadida demo interactiva a la web oficial; `demo.html` sirve para desarrollo local.
- Añadidos apilado expandible, límite visible configurable y pausa del temporizador en hover y pestañas ocultas.
- Añadidos roles y regiones vivas accesibles, cierre con Escape y soporte de movimiento reducido.
- Añadidos tema automático y variables CSS públicas para personalización.
- Añadido wrapper React opcional en `@pablotheblink/flashyjs/react`.
- Añadidos build ESM/CJS/UMD minificado y pruebas con `node:test`.
- Conservada la API 1.x y el fichero `flashy.js`. El empaquetado principal cambia a `dist/` y el entorno Node mínimo pasa a 18.

## 1.0.5

- Rediseño visual moderno.
